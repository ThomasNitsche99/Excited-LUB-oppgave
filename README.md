# LUB oppgave for Excited

1) `UiO` inneholder script for å hente ut LUB fra definerte studieprogrammer ved Universitetet i Oslo sine API'er og nettsider. Se README i mappen [UiO](/UiO/README.md) for mer informasjon om hvordan bruke scriptet. 

2) `USN` inneholder script for å hente ut LUB fra definerte studieprogrammer ved Universitetet i Sørøst-Norge sine nettsider . Se README i mappen [USN](/USN/README.md) for mer informasjon om hvordan bruke scriptet. 

3) `HVL` inneholder script for å hente ut LUB fra definerte studieprogrammer ved Høgskolen på vestlandet sine nettsider. Se README i mappen [HVL](/HVL/README.md) for mer informasjon om hvordan bruke scriptet. 

4) `Kristiania` inneholder script for å hente ut LUB fra definerte studieprogrammer ved Høyskolen Kristiania sine nettsider. Se README i mappen [Kristiania](/Kristiania/README.md) for mer informasjon om hvordan bruke scriptet. 

5) `UIA` inneholder script for å hente ut LUB fra definerte studieprogrammer ved Universitetet i Agder sine nettsider. Se README i mappen [UIA](/UIA/README.md) for mer informasjon om hvordan bruke scriptet.
