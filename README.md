# LUB assignment for Excited

## Scripts for retrieving learning outcomes

1) `UiO` contains scripts for retrieving LUB from defined study programs at "Universitetet i Oslo" through their APIs and websites. See the README in the folder [UiO](/UiO/README.md) for more information on how to use the script.

2) `USN` contains scripts for retrieving LUB from defined study programs at "Universitetet i Sørøst-Norge" through their websites. See the README in the folder [USN](/USN/README.md) for more information on how to use the script.

3) `HVL` contains scripts for retrieving LUB from defined study programs at "Høgskolen på Vestlandet" through their websites. See the README in the folder [HVL](/HVL/README.md) for more information on how to use the script.

4) `Kristiania` contains scripts for retrieving LUB from defined study programs at "Høyskolen Kristiania" through their websites. See the README in the folder [Kristiania](/Kristiania/README.md) for more information on how to use the script.

5) `UIA` contains scripts for retrieving LUB from defined study programs at "Universitetet i Agder" through their websites. See the README in the folder [UIA](/UIA/README.md) for more information on how to use the script.

6) `HIOF` contains scripts for retrieving LUB from defined study programs at "Høgskolen i Østfold" through their websites. See the README in the folder [HIOF](/HIOF/README.md) for more information on how to use the script.

7) `UIB` contains scripts for retrieving LUB from defined study programs at "Universitetet i Bergen" through their websites. See the README in the folder [UIB](/UIB/README.md) for more information on how to use the script.

8) `NTNU` contains scripts for retrieving LUB from defined study programs at "NTNU" through their FSProd-API. See the README in the folder [NTNU](/NTNU/README.md) for more information on how to use the script.

## Tools

1) `txtToCsv.py` is a script for creating a single CSV file from a text file containing learning outcomes.
