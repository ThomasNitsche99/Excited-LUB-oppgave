# UIA LUB Scraping

This folder contains the logic for scraping the HVL websites to extract learning outcomes (LUB) from various study programs.

## Overview

This folder consist of one script [`uia_scraping_script.py`](../UIA/uia_scraping_script.py), which retrieves the learning outcomes from the study programs defined in the script. 

## Usage

Run the script [`uia_scraping_script.py`](../UIA/uia_scraping_script.py) for producing `.txt`files with the learning outcomes for each study program.

The rquirements (needed modules) for running the script is defined in [`Requirements.txt`](../UIA/requirements.txt)
