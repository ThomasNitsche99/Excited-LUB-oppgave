# UiB Learning Outcomes Scraping

This script scrapes the learning outcomes from the University of Bergen (UiB) "Bachelor i Digital Teknologi" study program webpage and saves them to a local `.txt` file.

## Overview

The script `uib_scraping_script.py` fetches and parses the learning outcomes section from the UiB webpage and stores the extracted content in a file named `uib_learning_outcomes.txt`.

## Output

The `.txt` files will be saved to the output folder

## Usage

Run the script [`uib_scraping_script.py`](../UIB/uib_scraping_script.py) for producing `.txt`files with the learning outcomes for each study program.
