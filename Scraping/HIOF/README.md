# HIOf Learning Outcomes Scraping

This script scrapes learning outcomes from HIOF study programs webpage and saves them to a local `.txt` file.

## Usage

Run `hiof_scraping_script.py` to produce a `.txt` file with the learning outcomes for the HIOf program.

New study programs can be added directly to the script, in the `study_programs` dictionary.

## Output

The `.txt` files will be saved to the output folder

## Requirements

Install the requirements using:

```bash
pip install -r requirements.txt
